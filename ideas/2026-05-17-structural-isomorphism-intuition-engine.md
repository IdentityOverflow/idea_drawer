# Structural Isomorphism Intuition Engine

Captured: 2026-05-17

## Raw idea

An intuition engine based on structural isomorphism rather than semantic similarity: represent domains as relational graphs, measure isomorphism between graphs rather than distance between embeddings, using the Sierpinski gasket both as inspiration and literal architecture — a fractal, multi-scale pattern matcher that stores transformation rules rather than concepts, asking which rules applied to domain A produce a structure domain B already has.

Target: replicating the subconscious operation of recognizing deep structural equivalence across apparently unrelated domains.

RO Framework DoF language as potential extraction primitive.
